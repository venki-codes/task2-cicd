📌 About the Project

Continuous Integration

GitHub Actions automatically installs dependencies and runs application tests whenever code is pushed or a pull request is created.

Docker Build

The application is packaged into a Docker image after the testing job completes successfully.

Docker Hub

The Docker image is automatically published to Docker Hub with latest and commit-specific tags.

Containerization

Docker allows the application to run inside an isolated container with its required environment.

⚙️ CI/CD Workflow

01. GitHub Repository

Developer pushes application code to GitHub.

02. GitHub Actions

The automated workflow starts.

03. Install Dependencies

Node.js environment is configured and npm ci runs.

04. Application Testing

npm test checks the application.

05. Docker Image Build

Docker builds the application image after successful tests.

06. Docker Hub Publishing

The image is pushed to Docker Hub.

07. Local Container

The image can be used to run the webpage in Docker.
